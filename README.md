# Teerapol Portfolio — React + Vite

## 🚀 Quick Start

```bash
# 1. เข้าโฟลเดอร์
cd teerapol-portfolio

# 2. ติดตั้ง dependencies
npm install

# 3. รัน dev server
npm run dev
```

จากนั้นเปิด http://localhost:5173 ใน browser

## 📦 Build for Production

```bash
npm run build
npm run preview
```

## 🗂 โครงสร้างไฟล์

```
src/
├── main.jsx          # entry point
├── index.css         # CSS variables & global styles
├── App.jsx           # root component
├── App.module.css
├── Navbar.jsx        # fixed top navbar
├── Navbar.module.css
├── Hero.jsx          # hero section
├── Hero.module.css
├── About.jsx         # certificate / internship record
├── About.module.css
├── Timeline.jsx      # 8-week journey timeline
├── Timeline.module.css
├── Research.jsx      # 3 research areas
├── Research.module.css
├── Skills.jsx        # tools & tech grid
└── Skills.module.css
```

## Tech Stack
- React 18 + Vite 5
- CSS Modules (no extra CSS framework)
- Space Grotesk font via Google Fonts
